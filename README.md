# 🏦 Modélisation Relationnelle et Stockage des Données Bancaires

## 1. Nom du projet

**Modélisation Relationnelle et Stockage des Données Bancaires**

---

# 2. Présentation du projet

Ce projet consiste à concevoir une base de données relationnelle permettant de stocker, organiser et analyser des données bancaires.

Il s'adresse principalement aux analystes de données, aux équipes informatiques et aux responsables souhaitant exploiter des données financières structurées.

Son objectif principal est de transformer des données bancaires brutes en une structure relationnelle fiable facilitant l'analyse et la prise de décision.

---

# 3. Problématique

Le problème identifié est que les données bancaires peuvent être stockées sous des formats non structurés, ce qui rend leur exploitation difficile et peut provoquer des incohérences.

La solution proposée permet de nettoyer les données, concevoir un modèle relationnel adapté et stocker les informations dans une base de données organisée afin de faciliter les analyses.

---

# 4. Fonctionnalités principales

- Importer les données bancaires depuis un fichier CSV.
- Nettoyer et préparer les données avant stockage.
- Concevoir un modèle relationnel adapté aux données bancaires.
- Créer les tables et les relations entre les différentes entités.
- Vérifier la cohérence et l'intégrité des données.
- Préparer les données pour les analyses futures.

---

# 5. Technologies utilisées

| Technologie | Utilisation dans le projet |
|------------|----------------------------|
| SQL | Création des tables, relations et requêtes d'analyse. |
| Python | Nettoyage et préparation des données. |
| Pandas | Manipulation et transformation du fichier CSV. |
| PostgreSQL | Stockage des données dans une base relationnelle. |
| CSV | Source initiale des données bancaires. |
| GitHub | Gestion des versions et partage du projet. |

Nous avons utilisé **Python et Pandas** pour nettoyer et préparer les données.

Nous avons utilisé **SQL** pour concevoir la structure relationnelle et gérer le stockage.

Nous avons utilisé **PostgreSQL** comme système de gestion de base de données.
